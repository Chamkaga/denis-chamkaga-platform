# Concrete Provider Drivers

This folder is designed to contain concrete implementations of external services.

## Driver Mappings:
- **Payment**: DPO (Direct Pay Online)
- **Notification**: Resend (Email), Twilio (SMS / WhatsApp)
- **Storage**: AWS S3 / Cloudinary (Media assets)
- **AI**: OpenAI (GPT-4o-mini / GPT-4o)
